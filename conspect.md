Цель: написать сервис, который сокращает длинные ссылки, хранит их в Redis и считает количество переходов.

1. Создание короткой ссылки
POST /shorten
Принимает:
{
  "url": "https://google.com"
}


Возвращает:
{
  "short_code": "aB12x",
  "short_url": "http://localhost:8000/aB12x"
}


Требования:
- Генерировать случайный код из 5–8 символов.
- Сохранять соответствие кода и URL в Redis.
- Ссылка должна автоматически удаляться через 24 часа.
- При совпадении кодов нельзя перезаписывать старую ссылку.

Подсказка: SET поддерживает параметры ex и nx.

GET /{short_code}
Сервис должен:
- Найти оригинальную ссылку в Redis.
- Увеличить счётчик переходов.
- Перенаправить пользователя на оригинальную ссылку через RedirectResponse.
- Вернуть 404, если ссылка отсутствует.
3. Статистика переходов
GET /stats/{short_code}
Возвращает:
{
  "short_code": "aB12x",
  "clicks": 15,
  "ttl": 82800
}


Здесь ttl — количество секунд до удаления ссылки.
